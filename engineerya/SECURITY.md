# Security Policy

## Supported Versions

We actively support security updates for the following versions of EngineerYa:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of EngineerYa seriously. If you find a security vulnerability, please do NOT report it publicly via GitHub issues. Instead, please report it via the following process:

1. **Email us**: Send a detailed report to [security@engineerya.com].
2. **Include details**: Describe the vulnerability, steps to reproduce, and any potential exploits or impact.
3. **Response time**: We will acknowledge your email within 48 hours and work with you to analyze and resolve the issue.
4. **Coordinated Disclosure**: We ask that you give us a reasonable amount of time (typically 90 days) to deploy a fix before publishing the vulnerability details to the public.
