# Public Materials Guide

## How to add new public materials

1. Put your files in the public/materials folder.
2. Use a public link such as `/materials/your-file.pdf`.
3. The materials page will show the file as a public resource.

## Recommended free storage options

- GitHub repository public files for small to medium files
- GitHub Releases for larger downloadable assets
- GitHub Pages static hosting for public web pages
- Google Drive public links only if you want a simple external backup

## Recommendation for many large files

For many large files, the best free approach is:
- keep the website on GitHub Pages,
- store large files in GitHub Releases or a public GitHub repo,
- and link them from the materials page.

This keeps the site free and public while allowing many downloads.
